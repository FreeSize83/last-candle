# Последняя свеча

Игра-блеф в таверне на перекрёстке миров. Души в масках (Козёл, Лис, Ворон, Кукла) играют в «Колоду лжеца», молчаливый Перевозчик ведёт игру. Проигравший пьёт из одной из шести чарок, и в одной из них яд. Последняя душа за столом возвращается в мир живых.

## Скачать

**[LastCandle-v0.5-windows.zip](LastCandle-v0.5-windows.zip)**: на странице файла нажмите «Download raw file» (кнопка со стрелкой вниз).

Распакуйте архив и запустите `Последняя свеча.exe`. Устанавливать ничего не нужно. Нужна Windows 10/11 64-bit и видеокарта с поддержкой Vulkan.

- Если Windows SmartScreen пишет «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». У игры нет цифровой подписи, поэтому Windows не знает издателя.
- При первом запуске брандмауэр спросит доступ к сети. Его нужно разрешить, иначе не получится играть по сети.

## Как играть

В свой ход положите на стол 1–3 карты рубашкой вверх и заявите, что все они — карта стола. Можно соврать. Вместо хода можно крикнуть «Лжец!» на предыдущего игрока, и тогда его карты вскрываются. Проверку проигрывает тот, кто ошибся, и он пьёт из чарки. Полные правила есть в игре: «Правила» в главном меню.

Управление: мышь — осмотреться; A / D — выбрать карту; Пробел — отметить (вне своего хода — поднять или опустить карты); E — разыграть; X — «Лжец!»; Q — оберег; Esc — пауза.

## Игра по сети (до 4 игроков)

Играть можно по локальной сети, через Hamachi или Radmin VPN. Все должны быть в одной сети, и у всех должна быть одна и та же версия игры.

1. Хост: «Игра по сети» → ввести ник → «Создать лобби». Друзьям нужно назвать адрес из Hamachi (25.x.x.x) или Radmin VPN (26.x.x.x). Он также показан в окне игры. Порт по умолчанию 7777.
2. Остальные: «Игра по сети» → ник → IP хоста → «Подключиться».
3. Хост нажимает «Начать: выбор персонажей». Каждый выбирает своего персонажа и нажимает «Готов». Партия начинается, когда готовы все.
4. После партии сразу начинается следующая, переподключаться не нужно.

Можно играть и одному против компьютерных соперников: «Начать игру».
